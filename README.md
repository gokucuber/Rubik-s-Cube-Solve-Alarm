# Cube Alarm

GAN12 ui Maglev を使って、キューブをそろえるまで止まらない目覚まし時計。

## できること

- 時刻になると鳴り出し、音量は設定秒数かけて上がっていく
- キューブを接続 → スクランブルが表示される → その通りに回す → 解く → 止まる
- モード
  - **回数だけ**: N回そろえれば止まる
  - **1回ごとにタイム制限**: X秒以内でN回。超えたら最初からやり直し（オフにもできる）
  - **合計タイム制限**: N回の合計がX秒以内
- アラーム音は好きな音声ファイルを指定可能（未指定なら電子音）
- タイムはBLEパケットの到着時刻ではなく、キューブが報告するムーブのタイムスタンプで測る

## 動かす

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # キューブ状態エンジンとモード判定の自己チェック
npm run build
```

Web Bluetooth は **HTTPS か localhost でしか動きません**。PCのローカルIP
(`192.168.x.x`) でスマホから開くと弾かれます。実機で使うには下のデプロイをしてください。

## Galaxy S25 で使えるようにする

GitHub Pages に置くのが一番楽です。

1. このディレクトリをGitHubにpush（publicリポジトリ）
2. リポジトリの Settings → Pages → Source を **GitHub Actions** に変更
3. `.github/workflows/deploy.yml` が動いて `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開される
4. Galaxy の Chrome でそのURLを開き、メニューから「ホーム画面に追加」

## 使い方

**寝る前**

1. キューブをそろえて、ページの「キューブを接続して確認」を押す
   - バッテリー残量が表示される。30%を切っていたら充電する
   - 確認したら「切断する」を押してよい。接続を保ったまま寝ると一晩分のバッテリーを使う
   - 繋いだままにしておけば、朝は接続手順を飛ばせる
2. 時刻とモードを設定して「アラームをセット」
3. スマホを充電器につないで枕元へ。**画面は自動で点いたままになる**（Wake Lock）

**朝**

1. 鳴る。スマホを取る
2. キューブ未接続なら「接続する」を押す
3. キューブがそろっていなければ、まずそろえる（この1回は回数に入らない）
4. 表示されたスクランブルを**白上・緑前**で適用する。残り面数がリアルタイムで減る
5. スクランブルが完成したら、次に回した瞬間からタイマーが走る
6. 条件を満たすまで繰り返し

**緊急停止**: 画面下のボタンを10秒長押し。キューブのバッテリーが朝に切れた場合の逃げ道です。

## 既知の制約

- **ページを開いたままにしておく必要があります。** ブラウザは自分を起動できないので、
  「朝になると勝手にアプリが立ち上がる」はWeb版では実現できません。ネイティブのAndroidアプリ
  （AlarmManager + full-screen intent）に移植すれば可能になります
- CubeStationなど他のキューブアプリが起動していると接続を奪われます。アラーム運用中は起動しないこと
- スクランブルはランダムムーブ方式です。WCA公式のランダムステート方式にしたい場合は
  `cubing` パッケージの `randomScrambleForEvent("333")` に差し替えてください
  （`src/cube.ts` の `randomScramble` だけ置き換えれば済みます）

## 構成

| ファイル | 役割 |
|---|---|
| `src/cube.ts` | 54面の状態エンジン。ムーブの置換表は3D幾何から生成しているので手書きミスが起きない |
| `src/challenge.ts` | スクランブル検証・計測・モード判定の状態機械。UIもBLEも知らない |
| `src/conn.ts` | gan-web-bluetooth のラッパ。MAC処理、1秒ごとの状態再同期、切断検出 |
| `src/alarm.ts` | 音量ランプ付きアラーム、電子音フォールバック、Wake Lock |
| `src/store.ts` | 設定はlocalStorage、音声ファイルはIndexedDB |
| `src/main.ts` | 画面遷移とイベント配線 |

`cube.ts` は GAN公式ドキュメントに載っている `F R` 適用後の facelet 文字列と
一致することをテストで確認しています。
